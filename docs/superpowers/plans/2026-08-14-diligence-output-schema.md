# Diligence Output Schema Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `@solarhack/schema`, the typed contract carrying a multi-agent due-diligence fan-out to the React frontend, plus the frontend hook that consumes it.

**Architecture:** Zod is the single source of truth: `z.infer` produces frontend types, `z.toJSONSchema` produces the agent structured-output contract. Agents emit only judgments (likelihood, impact, evidence, quotes); shared pure functions in `scoring.ts` derive every number. A single `reduceRunEvent` is imported by both the frontend hook and the server's replay endpoint, so the live stream and the REST snapshot cannot drift.

**Tech Stack:** npm workspaces, TypeScript 5.7, Zod 4.4.3, Vitest 4.1.10, React 19, Vite 6.

**Spec:** `docs/superpowers/specs/2026-08-14-diligence-output-schema-design.md`

## Global Constraints

- Zod version `^4.4.3` — `z.toJSONSchema` is a Zod 4 built-in; do not add `zod-to-json-schema`.
- All JSON Schema exports use `{ target: 'draft-2020-12', io: 'output', reused: 'inline' }`.
- Factor weights are exactly: land `0.20`, law `0.20`, finance `0.25`, materials `0.20`, demand `0.15`.
- Severity bands on `riskScore`: `>= 20` critical, `>= 12` high, `>= 6` medium, else low.
- `readinessScore = 100 - 4 * avgRiskScore`, `null` when the factor has no findings.
- `overallReadiness` renormalises weights across scored factors only.
- Floating-point assertions use `toBeCloseTo(x, 2)`; the source workbook stores `26.000000000000004`.
- Agents never emit `riskScore`, `severity`, `id`, or any `FactorScore` field. Code derives all of them.
- Every module is ESM (`"type": "module"`). Test files are `*.test.ts` beside their source.

**Anthropic API constraints that shape this package** (confirmed against the TypeScript SDK docs):

- The Anthropic path consumes Zod **directly** via `zodOutputFormat(Schema)` from `@anthropic-ai/sdk/helpers/zod`. `jsonschema.ts` (Task 8) is therefore a *provider-agnostic secondary* export, not the primary contract — build it, but don't treat it as the path the agent layer will use.
- Structured outputs do **not** support `minLength` / `maxLength` / `minimum` / `maximum`. The SDK strips those keywords from the schema it sends and validates them client-side. So `likelihood: z.int().min(1).max(5)` constrains the *parse*, not the *generation* — an agent can return `7` and the parse fails. Schemas must therefore stay strict (the bound is the point), and the backend owns the retry. This is why `parseRunEvent` returns `null` rather than throwing.
- Citations (`citations: {enabled: true}`) and `output_config.format` are mutually exclusive — combining them returns a 400. Extraction is consequently two-pass in the backend: a citations-enabled pass yields API-provided `page_location` values, then a structured pass normalizes them into `Claim`s. `Locator.pdf_page` therefore carries a *verified* page number, which is what makes the evidence drawer trustworthy.

**Deviations from the spec**, both flagged for review before execution:

1. The `scores.updated` event is dropped from `RunEvent`. The reducer derives `FactorScore[]` from `state.findings` using the same `scoreFactors` the server would call, and derives `confidence` from `AgentState.status`. A transmitted score could only agree with the derived one or corrupt it.
2. Fixtures are TypeScript (`solar-alpha.events.ts`), not the `.json` pair the spec named. The event stream is *built from* `REGISTER_ROWS`, so it cannot drift from the workbook transcription, and the golden `RunReport` is replaced by assertions against the `WORKBOOK_*` constants. A checked-in golden JSON would have to be regenerated by the code it is meant to check.

Create `shared/src/scoring.ts`. No Zod here — this module is pure arithmetic so it can be called identically by the server, the reducer, and tests:

```ts
import { FACTORS, FACTOR_WEIGHTS, type Factor } from './factors.js'

/** Tuple, not Severity[] — z.enum(SEVERITIES) needs the literal types preserved. */
export const SEVERITIES = ['critical', 'high', 'medium', 'low'] as const

export type Severity = (typeof SEVERITIES)[number]

/**
 * Lower bound of each band on riskScore. Calibrated against all 16 workbook
 * rows: 25 and 20 are Critical, 16 and 12 are High, 9 is Medium. The medium
 * cut at 6 is unconstrained by the data and is a documented default.
 */
export const SEVERITY_THRESHOLDS = { critical: 20, high: 12, medium: 6 } as const

/** The workbook's =F*G formula. */
export function riskScoreOf(likelihood: number, impact: number): number {
  return likelihood * impact
}

export function severityOf(riskScore: number): Severity {
  if (riskScore >= SEVERITY_THRESHOLDS.critical) return 'critical'
  if (riskScore >= SEVERITY_THRESHOLDS.high) return 'high'
  if (riskScore >= SEVERITY_THRESHOLDS.medium) return 'medium'
  return 'low'
}

export interface ScoreInput {
  factor: Factor
  riskScore: number
}

export interface FactorScore {
  factor: Factor
  weight: number
  riskCount: number
  avgRiskScore: number | null
  maxRiskScore: number | null
  criticalCount: number
  highCount: number
  /** 100 - 4*avg, or null when the factor has no findings. */
  readinessScore: number | null
  confidence: 'ok' | 'low'
}

export function severityCounts(inputs: ScoreInput[]): Record<Severity, number> {
  const counts: Record<Severity, number> = { critical: 0, high: 0, medium: 0, low: 0 }
  for (const input of inputs) counts[severityOf(input.riskScore)] += 1
  return counts
}

export function scoreFactors(inputs: ScoreInput[], lowConfidence: Factor[] = []): FactorScore[] {
  const low = new Set(lowConfidence)

  return FACTORS.map((factor) => {
    const scores = inputs.filter((i) => i.factor === factor).map((i) => i.riskScore)
    const confidence = low.has(factor) ? 'low' : 'ok'

    if (scores.length === 0) {
      return {
        factor,
        weight: FACTOR_WEIGHTS[factor],
        riskCount: 0,
        avgRiskScore: null,
        maxRiskScore: null,
        criticalCount: 0,
        highCount: 0,
        readinessScore: null,
        confidence,
      }
    }

    const avg = scores.reduce((sum, s) => sum + s, 0) / scores.length

    return {
      factor,
      weight: FACTOR_WEIGHTS[factor],
      riskCount: scores.length,
      avgRiskScore: avg,
      maxRiskScore: Math.max(...scores),
      criticalCount: scores.filter((s) => severityOf(s) === 'critical').length,
      highCount: scores.filter((s) => severityOf(s) === 'high').length,
      readinessScore: 100 - 4 * avg,
      confidence,
    }
  })
}

export function unscoredFactors(scores: FactorScore[]): Factor[] {
  return scores.filter((s) => s.readinessScore === null).map((s) => s.factor)
}

/**
 * Weighted mean of the factors that actually scored. The divisor renormalises
 * so an unscored factor reads as unknown rather than as maximum risk.
 */
export function overallReadiness(scores: FactorScore[]): number | null {
  const scored = scores.filter(
    (s): s is FactorScore & { readinessScore: number } => s.readinessScore !== null,
  )
  if (scored.length === 0) return null

  const weightSum = scored.reduce((sum, s) => sum + s.weight, 0)
  if (weightSum === 0) return null

  const weighted = scored.reduce((sum, s) => sum + s.weight * s.readinessScore, 0)
  return weighted / weightSum
}
```

```ts
import { z } from 'zod'
import { CitationSchema } from './citation.js'
import { FactorSchema } from './factors.js'
import { SEVERITIES, riskScoreOf, severityOf } from './scoring.js'

export const SeveritySchema = z.enum(SEVERITIES)

/**
 * What a factor-analyst agent returns. Judgments only: no id, no riskScore, no
 * severity. Zod strips unknown keys by default, so an agent that volunteers a
 * severity has it discarded rather than honoured.
 */
export const FindingDraftSchema = z.object({
  factor: FactorSchema,
  subfactor: z.string().min(1),
  title: z.string().min(1).max(200),
  evidence: z.string().min(1).max(1000),
  likelihood: z.int().min(1).max(5),
  impact: z.int().min(1).max(5),
  owner: z.string().min(1),
  mitigation: z.string().min(1),
  citations: z.array(CitationSchema).min(1),
  claimIds: z.array(z.string()),
})

export type FindingDraft = z.infer<typeof FindingDraftSchema>

export const FindingSchema = FindingDraftSchema.extend({
  id: z.string().regex(/^RF-\d{3,}$/),
  riskScore: z.int().min(1).max(25),
  severity: SeveritySchema,
})

export type Finding = z.infer<typeof FindingSchema>

export function formatFindingId(n: number): string {
  return `RF-${String(n).padStart(3, '0')}`
}

/** The single bridge from agent judgment to wire entity. */
export function widenFinding(draft: FindingDraft, index: number): Finding {
  const riskScore = riskScoreOf(draft.likelihood, draft.impact)
  return {
    ...draft,
    id: formatFindingId(index),
    riskScore,
    severity: severityOf(riskScore),
  }
}
```

```ts
import { z } from 'zod'
import { FACTORS, FactorSchema, documentById, type Factor } from './factors.js'

export const AgentStageSchema = z.enum(['extract', 'analyze', 'synthesize'])

export type AgentStage = z.infer<typeof AgentStageSchema>

export const AgentStatusSchema = z.enum([
  'pending',
  'running',
  'succeeded',
  'failed',
  'skipped',
])

export type AgentStatus = z.infer<typeof AgentStatusSchema>

export const AgentStateSchema = z.object({
  id: z.string().min(1),
  stage: AgentStageSchema,
  label: z.string().min(1),
  /** Set for extract-stage agents. */
  docId: z.string().optional(),
  /** Set for analyze-stage agents. */
  factor: FactorSchema.optional(),
  status: AgentStatusSchema,
  startedAt: z.string().optional(),
  finishedAt: z.string().optional(),
  error: z.string().optional(),
  stats: z
    .object({
      claims: z.int().optional(),
      findings: z.int().optional(),
      conflicts: z.int().optional(),
      tokensIn: z.int().optional(),
      tokensOut: z.int().optional(),
    })
    .optional(),
})

export type AgentState = z.infer<typeof AgentStateSchema>

/**
 * A factor is low confidence when evidence that should have reached it did
 * not: its analyst failed, or an extractor feeding it was skipped or failed.
 * Returned in registry order so output is stable.
 */
export function lowConfidenceFactors(agents: AgentState[]): Factor[] {
  const degraded = new Set<Factor>()

  for (const agent of agents) {
    if (agent.status !== 'failed' && agent.status !== 'skipped') continue

    if (agent.factor) degraded.add(agent.factor)
    if (agent.docId) {
      for (const factor of documentById(agent.docId)?.factors ?? []) degraded.add(factor)
    }
  }

  return FACTORS.filter((f) => degraded.has(f))
}
```

```ts
import { lowConfidenceFactors, type AgentState } from './agent.js'
import { RunEventSchema, type RunEvent } from './events.js'
import { emptyReport, type RunMeta, type RunReport } from './report.js'
import { overallReadiness, scoreFactors, severityCounts, unscoredFactors } from './scoring.js'

/** Validate an untrusted wire message. Returns null instead of throwing so a
 *  single malformed event cannot blank the dashboard. */
export function parseRunEvent(raw: unknown): RunEvent | null {
  const result = RunEventSchema.safeParse(raw)
  return result.success ? result.data : null
}

/** Replace by id if present, otherwise append. Keeps events idempotent. */
function upsertById<T extends { id: string }>(list: T[], item: T): T[] {
  const index = list.findIndex((existing) => existing.id === item.id)
  if (index === -1) return [...list, item]
  const next = [...list]
  next[index] = item
  return next
}

/** Recompute every derived number from the entities currently in state. */
function withDerived(state: RunReport, agents: AgentState[] = state.agents): RunReport {
  const inputs = state.findings.map((f) => ({ factor: f.factor, riskScore: f.riskScore }))
  const scores = scoreFactors(inputs, lowConfidenceFactors(agents))

  return {
    ...state,
    scores,
    overallReadiness: overallReadiness(scores),
    unscoredFactors: unscoredFactors(scores),
    counts: severityCounts(inputs),
  }
}

export function reduceRunEvent(state: RunReport, event: RunEvent): RunReport {
  switch (event.type) {
    case 'run.started':
      return { ...state, meta: event.run, status: 'running', startedAt: event.ts }

    case 'agent.updated': {
      const agents = upsertById(state.agents, event.agent)
      const errors =
        event.agent.status === 'failed' && event.agent.error
          ? upsertError(state.errors, {
              agentId: event.agent.id,
              message: event.agent.error,
              at: event.ts,
            })
          : state.errors
      return withDerived({ ...state, agents, errors }, agents)
    }

    case 'claim.found':
      return { ...state, claims: upsertById(state.claims, event.claim) }

    case 'finding.found':
      return withDerived({ ...state, findings: upsertById(state.findings, event.finding) })

    case 'conflict.found':
      return { ...state, conflicts: upsertById(state.conflicts, event.conflict) }

    case 'run.finished':
      return { ...state, status: event.status, finishedAt: event.ts }
  }
}

type RunError = RunReport['errors'][number]

function upsertError(errors: RunError[], error: RunError): RunError[] {
  const index = errors.findIndex((e) => e.agentId === error.agentId)
  if (index === -1) return [...errors, error]
  const next = [...errors]
  next[index] = error
  return next
}

/** Build a report from scratch — used by the server's GET /runs/:id replay. */
export function replayEvents(meta: RunMeta, events: RunEvent[]): RunReport {
  return events.reduce(reduceRunEvent, emptyReport(meta))
}
```

- [ ] **Step 4: Write the mock stream**

Create `frontend/src/lib/mockRunStream.ts`:

```ts
import type { RunEvent } from '@solarhack/schema'

export interface MockStreamOptions {
  /** Delay between events, in milliseconds. */
  intervalMs?: number
  onDone?: () => void
}

/**
 * Replays a recorded event stream with timing so the frontend can be developed
 * against the real contract before the agent layer exists.
 * Returns a cancel function.
 */
export function mockRunStream(
  events: readonly RunEvent[],
  onEvent: (event: RunEvent) => void,
  options: MockStreamOptions = {},
): () => void {
  const { intervalMs = 120, onDone } = options
  let index = 0
  let cancelled = false
  let timer: ReturnType<typeof setTimeout> | undefined

  const tick = () => {
    if (cancelled) return
    if (index >= events.length) {
      onDone?.()
      return
    }
    onEvent(events[index]!)
    index += 1
    timer = setTimeout(tick, intervalMs)
  }

  timer = setTimeout(tick, intervalMs)

  return () => {
    cancelled = true
    if (timer !== undefined) clearTimeout(timer)
  }
}
```

- [ ] **Step 5: Write the hook**

Create `frontend/src/lib/useRunStream.ts`:

```ts
import {
  emptyReport,
  parseRunEvent,
  reduceRunEvent,
  type RunEvent,
  type RunMeta,
  type RunReport,
} from '@solarhack/schema'
import { useEffect, useReducer, useState } from 'react'
import { mockRunStream } from './mockRunStream.js'

export type RunSource =
  | { kind: 'sse'; url: string; meta: RunMeta }
  | { kind: 'mock'; meta: RunMeta; events: readonly RunEvent[]; intervalMs?: number }

export interface RunStreamResult {
  report: RunReport
  connected: boolean
  error: string | null
}

/**
 * Subscribes to a run and folds its events into a RunReport using the same
 * reducer the server uses for GET /runs/:id, so the live view and a reload
 * cannot disagree.
 */
export function useRunStream(source: RunSource): RunStreamResult {
  const [report, dispatch] = useReducer(reduceRunEvent, source.meta, emptyReport)
  const [connected, setConnected] = useState(false)
  const [error, setError] = useState<string | null>(null)

  useEffect(() => {
    setError(null)

    const handle = (raw: unknown) => {
      const event = parseRunEvent(raw)
      if (event === null) {
        // A malformed event is dropped, never fatal: the dashboard keeps rendering.
        console.warn('[useRunStream] dropped malformed event', raw)
        return
      }
      dispatch(event)
    }

    if (source.kind === 'mock') {
      setConnected(true)
      const cancel = mockRunStream(source.events, handle, { intervalMs: source.intervalMs })
      return () => {
        cancel()
        setConnected(false)
      }
    }

    const es = new EventSource(source.url)
    es.onopen = () => setConnected(true)
    es.onmessage = (message) => {
      try {
        handle(JSON.parse(message.data))
      } catch {
        console.warn('[useRunStream] dropped unparseable payload', message.data)
      }
    }
    es.onerror = () => {
      setConnected(false)
      setError('stream disconnected')
    }

    return () => {
      es.close()
      setConnected(false)
    }
  }, [source.kind, source.meta, (source as { url?: string }).url, (source as { events?: readonly RunEvent[] }).events])

  return { report, connected, error }
}
```
